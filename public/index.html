HOW TO READ THIS DASHBOARD

Model output is not a personal sensor.

Outdoor pollution values are gridded model estimates for the selected coordinates. “Retrieved” is when this app received the response; “observed” is the provider’s current model timestamp.

If the provider is unavailable, the app shows “Unavailable” and no substitute reading. Hourly values are forecasts, not measurements.

Household suggestions use only the options you chose. They cannot predict personal exposure or health outcomes.
